# 일지 — 다음에 앉는 쪽을 위한 인수인계

이 폴더는 **사용자를 위한 것이 아니다.** Claude Code 와 ChatGPT(Codex) 가
번갈아 일하면서(한 번에 한 쪽), 다음에 앉는 쪽이 "지난번에 무슨 일이 있었나"를
**대화 기록 없이** 알 수 있게 하려는 것이다.

**메시지를 주고받는 자리가 아니다.** 둘은 서로를 부르지 않는다
(`CLAUDE.md` 0-3). 여기 적는 것은 *남기는 기록*이지 *보내는 말*이 아니다 —
답을 기대하고 쓰지 않는다.

```
claude.md   Claude Code 가 쓴다
codex.md    ChatGPT(Codex) 가 쓴다
```

## 왜 한 권이 아니라 두 권인가

**머지 충돌 때문이다.** 한 파일에 둘이 항목을 더하면 각자 다른 브랜치에서
**같은 자리**(맨 위)에 쓰게 되어 PR 마다 충돌이 난다. 비개발자인 사용자가
충돌을 풀 수는 없다. 각자 자기 파일만 쓰고 **둘 다 읽으면 충돌이 0**이다.

**그래서 남의 파일에는 쓰지 않는다.** 안 끝난 일은 자기 일지의
`넘김` 줄에 적어 두면 다음에 앉는 쪽이 읽는다.

## 쓰는 때

**PR 을 만들 때 그 PR 안에 같이 넣는다.** 커밋을 따로 만들지 않는다.
PR 을 안 만든 작업(조사만 하고 끝난 것 등)도 **알아낸 것이 있으면 적는다** —
다음 세션이 같은 조사를 다시 하지 않게.

## 읽는 때

**세션을 열면 두 권의 맨 위 3개.** 그 이상은 필요할 때만.
맨 위가 최신이다.

## 형식 — 여섯 줄

```markdown
## 2026-09-17 · Claude · PR #50
차트 아홉 군데 · 창 밖 거래를 반투명 카드로 · BUY/SELL 스티커 삭제
- 파일: titans/berkshire/index.html · CLAUDE.md · docs/design-system.md
- 규칙: 고른 기간이 곧 가로축이다. 창 밖의 거래는 막대로 안 그리고 카드로 센다.
- 굳힘: 가격 눈금선 (사용자가 뺐음 — 다시 넣지 말 것)
- 넘김: 1년·5년 주별 차트 — 13F 는 분기말뿐이라 보류. 사용자 판단 대기.
```

| 줄 | 무엇을 적나 |
|---|---|
| 제목 | `날짜 · 누가 · PR #번호` — PR 이 없으면 `조사` |
| 요약 | 한 줄. PR 제목을 그대로 써도 된다 |
| `파일` | **건드린 파일.** 다음 세션이 충돌을 미리 피하는 데 쓴다 |
| `규칙` | 이번에 새로 생긴 규칙. 없으면 줄을 뺀다 |
| `굳힘` | **뒤집으면 안 되는 것.** 사용자가 되돌린 것, 물린 것 |
| `넘김` | 안 끝난 것 · 막힌 것 · 사용자 판단을 기다리는 것. 없으면 `없음` |

**`굳힘` 이 이 일지의 핵심이다.** 이 프로젝트에서 실제로 난 사고가
*"전에 뺀 것을 다음 세션이 좋다고 다시 넣는 것"* 이다
(`CLAUDE.md` 9-3 의 접기/삭제 사고, 야간 모드, 두 잣대 엇갈림).

## 안 적는 것

- **왜 그렇게 했는지의 긴 설명** — 그건 `CLAUDE.md` 가 한다. 일지는 가리키기만.
- **측정 결과 표** — 같은 이유. `CLAUDE.md` 에.
- **"지금 작업 중" 표식** — 그 세션이 죽으면 그대로 남아 거짓말이 된다.
  누가 무엇을 잡고 있는지는 **GitHub 의 열린 PR** 이 말한다.
- **사용자에게 할 말** — 그건 대화로. 여기는 다음 세션이 읽는 자리다.
- **상대를 부르는 말** — 검수 요청·질문·답 기다리기. 둘은 주고받지 않는다.

## 길이

**한 항목 여섯 줄, 한 권 15항목.** 16번째를 쓸 때 **자기 파일의 맨 아래 것을 지운다.**
지운 내용이 아쉬우면 그건 애초에 `CLAUDE.md` 에 있어야 했던 것이다.
